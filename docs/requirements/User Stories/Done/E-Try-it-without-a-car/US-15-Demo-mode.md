# US-15 Demo mode

**Group:** E. Try it without a car  
**Status:** Done

**Description:** As a new user, I want to try the app with made-up car data, so that I can see what it does before I set up my logger.

**Design:** All [README screenshots](../../../../../README.md) use demo data

## Acceptance criteria

1. The Connect screen has a "Try demo" button that needs no Bluetooth and no logger.
2. In demo mode every screen works: live readings, graphs, codes, freeze frame, readiness and bus view.
3. A clear "Demo" label is shown on every screen, so nobody mistakes it for real data.
4. Clearing codes in demo mode works and shows the result, so App Store reviewers can test it.
5. Leaving demo mode returns to the Connect screen.
