# US-06 Graph one reading

**Group:** B. Watch my car live  
**Status:** Done

**Description:** As a car owner, I want to see one reading as a chart over the last few seconds, so that I can spot spikes and trends.

**Design:** [Graph screen, Simple](../../../../screenshots/graph-simple.png) · [Racing](../../../../screenshots/graph-racing.png)

## Acceptance criteria

1. Tapping any reading on the Live screen opens its graph.
2. The graph shows the last 18 seconds and scrolls as new values arrive.
3. Min, average and max for the shown window are displayed under the chart.
4. Missing values leave a gap in the line instead of dropping to zero.
5. Going back to Live and returning keeps the history already collected.
