# US-10 Check readiness monitors

**Group:** C. Find out what is wrong  
**Status:** Done

**Description:** As a car owner, I want to see which emission self-tests are done, so that I know if my car is ready for an inspection.

**Design:** [Codes screen](../../../../screenshots/codes-simple.png) (readiness section)

## Acceptance criteria

1. Each monitor the car supports is listed as "Complete" or "Not complete".
2. Monitors the car does not have are not shown.
3. A short note explains that "Not complete" is normal right after codes were cleared or the battery was disconnected.
4. The list refreshes when the user pulls down on the Codes screen.
