# US-03 Learn how to flash the right firmware

**Group:** A. Get connected  
**Status:** ToDo

**Description:** As a car owner, I want step-by-step help to put the OBD Live firmware on my ONE+, so that the app works without me searching forums.

**Design:** None yet. Needs a new screen or web page.

## Acceptance criteria

1. The Connect screen has a "Set up your logger" link that is visible before any logger is found.
2. The guide lists what is needed (ONE+ model, USB cable, computer) and the steps in order, with one picture per step.
3. The guide links to the exact firmware build from the `obd-live-ble` branch.
4. The last step tells the user how to check that it worked (the logger shows up on the Connect screen).
5. The guide can be read in under 5 minutes and works offline or from a stable web link.
